# Rhodes Island Voice Archive

An Arknights fansite where you can listen/read operator's voice records and switch easily between languages.

The two folders of this repo are for the two parts of this project: the part that organizes the data into something the site can read (`datascript`), and the site itself (`site`). Look at the README in each folder for more details on how they're run. 

## The README in the respective folders
- For the [data](datascript/README.md)
- For the [site](site/README.md)
